# 多旋翼无人机硬件组成及系统架构报告

> 文档版本: v1.2
> 变更说明: 新增硬件重量/功耗预算分析表，以及故障安全紧急响应逻辑矩阵。



---

## 一、 引言

无人机是一个集成了机械结构、动力系统、嵌入式硬件、传感感知与自主控制算法的复杂系统。本文针对一款基于 PX4 飞控 与 NVIDIA Jetson 机载电脑 的自主飞行无人机，对其硬件组成、电气接口、通信协议、功耗分配及安全机制进行全面梳理。



---

## 二、 核心硬件组成

### 1. 动力系统 

* 无刷电机：采用 KV1300 规格的无刷电机，提供足够的推重比。
* 电子调速器：4合1 电调（如 50A 电调），支持 Dshot600 数字协议，具有响应速度快、回传电机状态等优点。
* **螺旋桨 **：采用三叶高效竞速桨叶（如 GF 7037），匹配电机输出曲线。

### 2. 飞控与计算平台 (Flight Control & Onboard Computer)

* **主飞控 **：基于 PX4 固件的飞控（如微空 NXT），负责底层姿态解算（IMU）、PID 闭环控制及电调信号输出。
* **机载算力平台 **：NVIDIA Orin NX，搭载 Ubuntu & ROS 系统，负责上层 SLAM 建图、路径规划及视觉识别等高算力任务。

### 3. 感知与导航传感器

* IMU (惯性测量单元)：三轴加速度计 + 三轴陀螺仪，采集高频姿态数据。
* **激光雷达 **：Livox Mid-360 3D 激光雷达，采用 100M 网口（UDP协议）连接机载电脑，提供高精度三维点云。
* 双目/单目相机：RGB 前视与下视相机，通过 USB 3.0/Type-C 协议连接机载电脑，用于目标识别与视觉定位。
* 光流与测距模组：采用优象光流模组，通过 UART 串口连接飞控（MAVLink 协议），提供无 GPS 环境下的低空定点能力。

### 4. 通信与遥控模块

* **接收机 **：R12DSM 接收机，通过 SBUS 协议向飞控传输遥控器通道数据。
* 数传/图传：提供机载电脑/飞控与地面站（QGC）之间的数据双向通信。

## 四、 动力学与控制方程

**四旋翼的升力与电调转速平方成正比，升力 $F_i$ 与反作用力矩 $M_i$ 满足如下关系：**

$$
F_i = C_F \Omega_i^2, \quad M_i = C_M \Omega_i^2 \quad (i=1,2,3,4)
$$

**其中 $C_F$ 为升力系数，$C_M$ 为力矩系数，$\Omega_i$ 为第 $i$ 个电机的角速度。**

**机体在机体坐标系下的三轴转动动力学方程为：**

$$
\tau_x = I_{xx} \dot{\omega}_x, \quad \tau_y = I_{yy} \dot{\omega}_y, \quad \tau_z = I_{zz} \dot{\omega}_z
$$

**式中：**

* **$\tau_x = C_F b (\Omega_2^2 + \Omega_3^2 - \Omega_1^2 - \Omega_4^2)$**
* **$\tau_y = C_F a (\Omega_2^2 + \Omega_4^2 - \Omega_1^2 - \Omega_3^2)$**
* **$\tau_z = C_M (\Omega_1^2 + \Omega_2^2 - \Omega_3^2 - \Omega_4^2)$**

## 五、 电源管理与安全电路 

1. 电池供电：采用 6S (22.2V) 高倍率锂电池 (21700 6S1P) 为全机供电。
2. 分电板 (PDB)：
   * Direct 24V 输出：直接为 ESC 电调供电。
   * 12V Step-Down BEC：为 Livox Mid-360 激光雷达及图传模块供电。
   * 5V Step-Down BEC：为 PX4 飞控及传感器外设供电。
3. 安全设计：具备低压报警与紧急 Kill-Switch（遥控器一键切断电机输出）。

## 七、 故障安全与应急响应机制 — *[v1.2 新增]*

为保障飞行安全，系统在 PX4 飞控与上层机载电脑中部署了多级故障保护策略：

| 异常事件 (Event)          | 判定条件 (Trigger Condition)                           | 执行动作 (Action Protocol)                             | 优先级             |
| :------------------------ | :----------------------------------------------------- | :----------------------------------------------------- | :----------------- |
| **遥控信号中断**    | **超过 500ms 未收到 SBUS 数据包**                | **自动切换至`RTL` (返航) 或 `Hover` (悬停)** | **高**       |
| ****一级低电量 ****     | **单体电压$V_{\text{cell}} < 3.5\text{V}$ 持续 3s** | **触发地面站报警，限制最大爬升速度**             | **中**       |
| ****二级严重低电量 **** | **单体电压$V_{\text{cell}} < 3.3\text{V}$ 持续 2s** | **强制就地缓慢降落 (`Land`)**                  | **高**       |
| ****定位丢失 ****       | **视觉/激光里程计连续帧丢包 > 1s**               | **降级为光流/气压计姿态模式悬停**                | **最高**     |
| ****地面紧急切断 ****   | **遥控器 Kill 开关（SWD通道）触发**              | **飞控立即停止 PWM/Dshot 输出（切断电机）**      | **绝对优先** |

## 八、 总结

本报告梳理了无人机的四大硬件板块、控制逻辑链路、电气与功耗预算以及故障保护机制。在自主飞行系统中，机载电脑承担感知与规划，飞控承担底层稳态控制，二者通过 MAVLink 协议协同工作，结合高精度传感器与完善的安全机制，实现复杂环境下的精准自主导航与任务执行。
