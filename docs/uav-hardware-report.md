# 基于 PX4 与 ROS 的多旋翼无人机硬件系统组成报告

## 1. 引言

多旋翼无人机是一个高度集成的机电系统，其硬件架构通常由控制处理、动力提供、环境感知以及通信链路等核心模块构成。本报告以支持自主导航与环境感知的微型蜂群无人机为例，详细阐述其硬件组成及各子系统之间的工作机制。

## 2. 核心控制与处理系统

控制与处理系统是无人机的“大脑”，负责姿态解算、飞行控制以及高级算法（如视觉、SLAM、路径规划）的运行。

### 2.1 飞行控制器 

飞控是底层硬件控制的核心。常见的飞控（如 Pixhawk 系列、微空 NXT）内部集成了微处理器（MCU，如 STM32 系列），负责实时运行 PX4 或 ArduPilot 等开源飞控固件。其主要功能包括：

- **姿态解算**：读取板载 IMU（惯性测量单元）、气压计、磁罗盘等数据。
- **电机控制**：计算姿态误差，通过控制分配矩阵输出具体的电机转速指令。
- **故障保护**：实时监控电池电压与传感器健康状态。

### 2.2 机载计算机 

机载计算机（如 NVIDIA Jetson Orin NX / Raspberry Pi 5）主要处理对算力要求较高的高级应用任务。它与底层飞控通常通过 **UART 串口** 连接，并使用 **MAVLink 协议** 进行数据交互。其主要承担：

- 视觉处理与目标识别（YOLO 等深度学习算法）。
- 3D 激光雷达 SLAM（如 LOAM、FAST-LIO）。
- 全局/局部路径规划（如 EGO-Planner）。

## 3. 动力系统 

动力系统负责将电能转化为机械能，为无人机提供升力与机动性。为了维持悬停，动力系统产生的总推力必须克服重力，其基础动力学方程可表示为：

$\sum_{i=1}^{4} F_i \cos(\theta) = m g$

### 3.1 无刷电机 

提供直接旋转动力的执行机构。电机通常用 **KV 值** 来标定其转速特性，其理论空载转速与输入电压成正比：
$\text{RPM} = \text{KV} \times U$
其中 $U$ 为输入电压。对于挂载较多的无人机，通常选用低 KV 值的电机搭配大尺寸螺旋桨以获取更高的做功效率。

### 3.2 电子调速器 

电调负责接收来自飞控的数字控制信号（如 Dshot600 / PWM 协议），并将其转化为三相交流电（SPWM/FOC）来驱动无刷电机。常见的四合一电调能够极大简化机架走线并减轻重量。

### 3.3 螺旋桨

螺旋桨将电机的旋转转化为向上的升力。第 $i$ 个螺旋桨产生的升力 $F_i$ 与电机转速 $\Omega_i$ 的平方成正比：
$F_i = C_F \Omega_i^2$
其中 $C_F$ 为升力系数（Thrust Coefficient）。

### 3.4 能源模块

系统通常由高放电倍率的锂聚合物电池（LiPo）或锂离子电池（如 21700-6S1P 电池组）供电。配合分电板（PDB / Power Module），将 24V 的总线电压降压至 12V、5V，以供飞控、传感器与计算机安全运行。

## 4. 环境感知与传感器系统

感知系统为无人机提供了环境的先验与实时信息，是实现“自主”飞行的前提。

- **激光雷达**：如 Livox Mid-360，利用激光测距技术构建周围环境的高精度 3D 点云地图，是室内避障和建图的核心传感器。
- **视觉传感器 **：包括前视 RGB 相机（用于目标识别，如寻找靶心或抓取目标）与下视相机。
- **光流计 **：当失去 GPS 信号（如室内环境）时，光流计通过捕捉地面纹理的变化来计算无人机的水平平移速度 $v_x, v_y$。

## 5. 通信链路系统

确保人机交互以及多机协同的稳定信息传输。

- **遥控器与接收机**：飞手通过遥控器（如 AT9S Pro）发送控制指令，接收机（如 R12DSM）收到射频信号后，通过 **SBUS 协议** 将各通道的摇杆量输入给飞控，用于手动接管与紧急停机保护。
- **数传/图传模块**：通过 Wi-Fi 或特定频段射频将机载电脑的视频流、RViz 可视化数据和状态信息实时下传至地面控制站。

## 6. 总结

一架完备的自主无人机是软硬件高度协同的结晶。硬件层提供了强大的物理动力与多维度的环境感知信息，而在此基础之上运行的 ROS 软件架构和 PX4 飞控固件，则通过复杂的数学建模（状态估计、控制理论、规划算法）赋予了硬件“自主思考”的能力。
