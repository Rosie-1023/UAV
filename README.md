# UAV

多旋翼无人机硬件组成与系统架构报告（基于 PX4 飞控 + NVIDIA Jetson Orin NX 机载电脑）。

## 目录结构

```
UAV/
└── docs/
    └── uav-hardware-report.md    # 报告正文（唯一源文件）
```

## 报告内容

报告正文位于 [`docs/uav-hardware-report.md`](docs/uav-hardware-report.md)，涵盖以下部分：

| 章节 | 内容 |
|------|------|
| 一、引言 | 系统定位与硬件总体构成 |
| 二、核心硬件组成 | 动力系统、飞控与算力平台、感知与导航传感器、通信与遥控模块 |
| 三、系统电气与控制通信架构 | 各模块间接口、通信协议与数据速率对照表 |
| 四、动力学与控制方程 | 升力/力矩模型与机体三轴转动动力学方程 |
| 五、电源管理与安全电路 | 6S 电池、分电板 24V/12V/5V 分配、低压保护与 Kill-Switch |
| 六、质量与功耗预算分析 | 各模块电压、峰值功率与重量估算 |

## 涉及的主要硬件

- **飞控**：微空 NXT（PX4 固件）
- **机载电脑**：NVIDIA Jetson Orin NX（Ubuntu + ROS）
- **传感器**：Livox Mid-360 激光雷达、RGB 前视/下视相机、优象光流模组
- **动力**：F90 KV1300 电机、50A 四合一电调（Dshot600）、GF 7037 三叶桨
- **遥控**：AT9S Pro 遥控器 + R12DSM 接收机（SBUS）
- **电源**：21700 6S1P 锂电池 + 分电板（PDB）
